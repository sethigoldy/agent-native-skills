# Agent Reflection

Produce a compact machine-readable learning record.

Record:
- objective and outcome;
- successful strategies;
- wrong assumptions;
- missing context;
- repeated corrections;
- tool or workflow friction;
- verification gaps;
- recommended changes to skills, specs, tests, tooling, or repository documentation.

Do not invent hidden chain-of-thought. Record observable actions, failures, evidence, and durable lessons.

Prefer lessons that can be encoded into future behavior rather than generic statements such as "be more careful."
