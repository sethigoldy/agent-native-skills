# Skill Curator

Capture reusable knowledge without bloating every task.

## Procedure

1. Gather concrete repeated evidence: recurring failures, review comments, incidents, or successful workflows.
2. Decide whether the lesson belongs in a skill, spec template, rule, test, reference, or tooling change.
3. Create the smallest focused artifact that prevents the observed failure.
4. Keep the skill description precise enough for automatic selection.
5. Add an example or eval that demonstrates the behavior when practical.
6. Version the change and avoid duplicating rules already owned by another skill.
7. Revisit stale instructions as models and repositories evolve.
