# Incident Postmortem

Focus on system learning, not blame.

## Procedure

1. Establish a factual timeline.
2. Separate trigger, contributing conditions, and missing defenses.
3. Identify detection, containment, and recovery gaps.
4. Identify where human or agent assumptions differed from system reality.
5. Produce concrete corrective actions with verification criteria.
6. Turn durable lessons into tests, observability, rules, specs, skills, or architectural changes.
7. Verify that corrective actions close the original failure mode rather than only changing symptoms.
